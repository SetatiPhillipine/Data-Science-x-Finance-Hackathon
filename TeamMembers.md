# Git Workflow

Every team member must follow this workflow before contributing code.

1. Pull the latest changes from GitHub.
2. Switch to your assigned feature branch.
3. Make your changes.
4. Commit your work with a clear commit message.
5. Push your branch to GitHub.
6. Open a Pull Request.
7. Team Leader reviews and approves the Pull Request.
8. Merge into the `development` branch.
9. After testing is complete, merge `development` into `main`.
