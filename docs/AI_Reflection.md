# AI Reflection

# Finance Fraud Detection System

**Project:** Data Science Club Finance & Digital Innovation Hackathon

**Version:** 1.0

---

# Introduction

Artificial Intelligence (AI) tools were used during the planning, learning, and development phases of this project to support the team's understanding of unfamiliar concepts and improve productivity. AI served as an assistant rather than a replacement for human decision-making. All outputs generated by AI were reviewed, verified, modified where necessary, and tested by the team before being incorporated into the final solution.

---

# AI Tools Used

The following AI tool was used during the project:

- ChatGPT (OpenAI)

The AI tool was used responsibly to enhance learning and assist with technical tasks throughout the hackathon preparation and development process.

---

# How AI Was Used

AI was used to assist with the following activities:

- Understanding the problem statement.
- Learning data science concepts.
- Understanding machine learning algorithms.
- Explaining evaluation metrics such as Precision, Recall, Accuracy, and F1 Score.
- Understanding the Software Development Life Cycle (SDLC).
- Learning Python libraries including Pandas, NumPy, Matplotlib, and Scikit-learn.
- Assisting with GitHub repository organization.
- Creating documentation templates.
- Reviewing code for readability and best practices.
- Brainstorming possible fraud detection features.
- Assisting with React dashboard planning.

---

# How AI Was NOT Used

The team did not rely on AI to automatically complete the project.

AI did not:

- Make project decisions without team discussion.
- Generate final results without verification.
- Replace data analysis performed by the team.
- Replace testing or evaluation.
- Replace critical thinking or interpretation of the findings.

Every recommendation generated by AI was evaluated and adapted to suit the project requirements.

---

# Human Contribution

The team remained responsible for every stage of the project, including:

- Understanding the banking problem.
- Cleaning and preparing the dataset.
- Performing exploratory data analysis.
- Selecting suitable machine learning models.
- Evaluating model performance.
- Interpreting the results.
- Developing the React dashboard.
- Preparing documentation.
- Presenting the final solution.

All final decisions were made by the team members.

---

# Verification Process

To ensure the quality and reliability of AI-assisted work, the team followed these steps:

1. Read and understand AI-generated explanations.
2. Compare suggestions with official documentation where applicable.
3. Test all generated code before use.
4. Modify code to suit the project requirements.
5. Validate model outputs using evaluation metrics.
6. Review documentation for accuracy and consistency.

This process ensured that the final submission reflected the team's own understanding and work.

---

# Benefits of Using AI

Using AI provided several advantages during the project:

- Faster understanding of unfamiliar concepts.
- Improved learning of machine learning techniques.
- Better understanding of Python programming.
- Assistance with documentation.
- Improved project organization.
- Faster debugging of coding errors.
- Increased productivity during development.

---

# Challenges Encountered

Although AI was helpful, several challenges were identified:

- AI suggestions occasionally required modification.
- Some generated code was not immediately compatible with the project's environment.
- AI explanations sometimes lacked project-specific context.
- All outputs required human review before implementation.

These challenges reinforced the importance of testing and independent verification.

---

# Ethical Considerations

The team recognises the importance of using Artificial Intelligence responsibly.

Throughout the project, the team committed to:

- Maintaining academic integrity.
- Avoiding plagiarism.
- Giving credit to AI assistance where appropriate.
- Protecting confidential financial information.
- Avoiding misuse of generated content.
- Ensuring transparency regarding the use of AI.

The team understands that AI is a support tool and not a substitute for human knowledge, judgement, or accountability.

---

# Lessons Learned

Through the use of AI, the team gained a deeper understanding of:

- Data preprocessing.
- Exploratory Data Analysis (EDA).
- Machine learning workflows.
- Fraud detection techniques.
- Software engineering documentation.
- GitHub collaboration.
- Model evaluation methods.

The project also demonstrated the importance of combining AI assistance with critical thinking, teamwork, and technical skills.

---

# Conclusion

Artificial Intelligence played an important supporting role throughout this project by accelerating learning, improving productivity, and assisting with software development tasks. However, the success of the project depended on the team's ability to understand, verify, adapt, and apply the information responsibly.

The team believes that AI is most valuable when used ethically as a learning and productivity tool while maintaining human responsibility for all technical decisions, analysis, and final outcomes.
